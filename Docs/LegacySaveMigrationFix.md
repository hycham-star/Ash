# Legacy save migration correction

The user's screenshot confirmed `NOT SAVED — Save protected`, initial balances and a fresh map. Four uploaded copies of the two slots were byte-identical: valid checksum envelope1, payload version2, five resources, old armies/fragments/buildings, and no Scavenging field. Thus assignments created while loading was blocked were never written to these files. Existing game progress in the files remains recoverable; nonexistent saved assignments cannot be reconstructed.

The old UnityProgressCodec deserialized every version directly into the current ProgressState class. Unity can create empty instances of missing inline serialized classes, making Scavenging non-null for an old document with no such field. ProgressPersistence deliberately rejects Scavenging on version2, so that representation can reject both valid old slots, block writes and leave the new random temporary map visible. The initial Unity warning was cleared before the user's screenshot, so the exact native exception text was not captured. The correction removes this serializer-default dependency; native confirmation remains required.

ProgressJsonDecoder reads a version header and deserializes versions1/2 using their historical DTO field sets. It explicitly returns null only for fields outside those schemas: Buildings/Scavenging for version1, Scavenging for version2. Existing old fields proceed through complete unchanged domain validation/migration. Version3 is still read intact and validated strictly; missing/corrupt current maps are not silently regenerated. Future version protection remains. The envelope, current schema3, map generator, app identity and saved location remain unchanged. No original files are reset, rewritten by the analysis, or committed to the repository.

UnityProgressCodec delegates to the shared decoder with actual JsonUtility.FromJson(string,Type). GameManager also retains the blocked-load reason and logs it on manual Save; clearing Console no longer conceals why Save is blocked. The misleading recommendation to Reset is removed from the blocked-save status.
